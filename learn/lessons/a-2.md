- tier: challenge
- skill: worktree
- from: a-1

## ladder

### `.practice/a-2-choices.md` picks the cheapest pattern that fits each job
- narrow "There is no `.practice/a-2-choices.md`": Did you save the choices in that file, in the folder the check reads?

- narrow "which isn't one of the four patterns": Does each line name one of the four patterns right after the job number?
