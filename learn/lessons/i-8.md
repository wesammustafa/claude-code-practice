## ladder

### the committed `.claude/settings.json` enables a plugin from one of Anthropic's marketplaces
- narrow "that parses as JSON": Is the settings file committed, and does it still parse with the new block beside the old keys?
- narrow "turns on no plugin from Anthropic's marketplaces": Does the part after the @ name a marketplace, with the value true?
- hint: "If the first item fails, check the name after `@`: it's the marketplace's name, `claude-plugins-official`, not its repository."

### `.practice/i-8-plugins.json`, saved in this repository, shows that plugin installed at project scope and enabled
- narrow "In the repository, run": Is the list saved in the .practice folder of the repository the check reads?
- narrow "isn't JSON": Did the saved file get anything but the list, or was it cut short?
- narrow "doesn't show": Did you install at project scope in this repository, then save the list again?
- hint: "If the second fails, run the install command in the repository itself, then save the list again from there."
