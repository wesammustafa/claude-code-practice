## intro
- minutes: "about 15 minutes"
- why: "When a result is wrong, find out why before you turn a knob"
- can: "pick a model and an effort level for a task"
- can: "set them for a session or for one skill"
- can: "tell from a wrong result whether to raise the effort or pick a larger model"
- payoff: "set them for a session or for one skill"
- read: "[Choosing a Claude model and effort level in Claude Code](https://claude.com/blog/claude-model-and-effort-level-in-claude-code): Anthropic's guide to the two settings, with the "try or know" test this lesson uses."

## ladder

### the committed changelog skill runs a smaller model at low or medium effort
- narrow "is not committed. Run": Does `git status` still list the skill as new?
- narrow "There is no .claude/skills/changelog/SKILL.md": Is the skill saved at that path in this folder, the one the check reads?
- narrow "Set `model:` in the skill": Does the committed file still say TODO on its model line?
- narrow "picks a larger model than this task needs": Which row of the first table, on the lesson page (p), does a change you can describe precisely fall under?
- narrow "isn't a model alias or name": Is the model line spelled exactly as the first table spells the alias?
- narrow "Set `effort:` to one of": Does the committed file still say TODO on its effort line, or is the level misspelled?
- narrow "asks for a higher effort than a routine": Which effort does the first table, on the lesson page (p), give routine work, higher or lower?
- bottom: "git show HEAD:.claude/skills/changelog/SKILL.md | grep -E '^(model|effort):'"

### a committed CHANGELOG.md has an entry under `## Unreleased`
- narrow "There is no committed CHANGELOG.md": Did the commit include CHANGELOG.md, or only the change and the skill?
- narrow "has no `## Unreleased` heading": Does the committed CHANGELOG.md have a `## Unreleased` heading, or did you commit an older file?
- narrow "in CHANGELOG.md has no entry": Is the new list item under the Unreleased heading, starting with a dash?
- hint: "If there's no entry, stage a change before you run `/changelog`, because the skill reads only staged changes."
- bottom: "git show HEAD:CHANGELOG.md"
