## ladder

### `claude --version` prints a Claude Code version
- narrow "couldn't find": Can the terminal running this check find the installation?
- narrow "didn't finish within": Does the version command finish when you run it on its own?
- narrow "couldn't run": Does the installed executable have permission to run?
- narrow "printed": What version output and exit code did the command give?
- back: W1 Revisit the decision and evidence from this step before trying the same action again.

### the claim in `practice/b-1/onboarding.md` that the code contradicts is corrected
- narrow "This folder has no": Is this the practice copy that contains the onboarding note?
- narrow "is missing.": Is the original onboarding note still in your practice copy?
- narrow "The note still says": Which part of the claim disagrees with the cited source line?
- narrow "No line in the note": Does the corrected claim state the broken-link exit code?
