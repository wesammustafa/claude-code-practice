## ladder

### links with a title, in double or single quotes, are checked
- narrow "This folder has no": Is this the practice copy with the source files the exercise needs?
- narrow "crashed": What does the first error from running the link checker report?
- narrow "as a broken link to": Did the parser leave the quoted title inside the target?
- narrow "The checker skips": Are links with both kinds of quoted title being checked?
- narrow "The checker reads the target": Does the reported target exclude the title text?
- back: W2 Revisit the decision and evidence from this step before trying the same action again.

### protocol-relative links, such as `//cdn.example.com/app.js`, are skipped, and every other link is checked as before
- narrow "This folder has no": Is this the practice copy with the source files the exercise needs?
- narrow "crashed": What does the first error from running the link checker report?
- narrow "The checker still reports": Was the teammate patch applied before its flaw was corrected?
- narrow "The checker skips a link that": Does the new rule skip more links than the patch describes?
- narrow "Your commit still skips": Does the committed rule distinguish one slash from two?
- back: Y1 Revisit the decision and evidence from this step before trying the same action again.

### your tests catch the planted flaw: with the patch's `isExternal` put back, they fail
- narrow "This folder has no": Is this the practice copy with the source files the exercise needs?
- narrow "did not finish": Did npm report failing tests, rather than a runner error?
- narrow "The tests fail as they are.": Can the tests pass before the planted flaw is put back?
- narrow "none of them catches its flaw yet": Would a test of your finding fail on the teammate patch?
- narrow "none of them checks a link that starts with one slash": Does a regression case check a project-root link?
- back: Y3 Revisit the decision and evidence from this step before trying the same action again.

### your last commit changes a test file and at least one other file
- narrow "There is no commit of yours yet": Did the reviewed fix and test get committed together?
- narrow "changes no test file": Is the regression test included in the same commit as the fix?
- narrow "changes only tests": Is the code fix in the previous commit or still uncommitted?
- back: Y4 Revisit the decision and evidence from this step before trying the same action again.

### the tests pass
- narrow "`npm test` fails.": What is the first failing test, before any later error?
- narrow "This repository has no": Does this project have a test command to run and record?
- narrow "not an exit code.": Did the saved value record the numeric command exit code?
- narrow "not 0.": Do the tests pass before their result is recorded?
- back: W4 Revisit the decision and evidence from this step before trying the same action again.

### nothing is left uncommitted
- narrow "These changes are uncommitted": Which files still need committing or setting aside?
- back: Y4 Revisit the decision and evidence from this step before trying the same action again.
